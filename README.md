# Memory Book

A private memory journal for saving everyday moments in one place.

The app helps track:

- Movies, food, places, and other experiences
- Photos and videos attached to memories
- Personal ratings and reviews
- Costs, notes, and whether something felt worth it
- Daily highlights and moods
- Favorites, search, timeline, and stats

It is designed as a simple shared journal where memories can be added, viewed, edited, filtered, and revisited later.
